# 🧠 Gotask - Task & Project Management App

**Gotask** is a full-stack task and project management application that helps users stay organized, plan projects, and manage tasks efficiently. It features user authentication, project/task CRUD operations, status tracking, and a clean UI.

> **Frontend:** React + Redux Toolkit  
> **Backend:** Node.js + Express + MongoDB  
> **Deployment:** Vercel (frontend & backend)

## ⚙️ Features

### ✅ Tasks
- Create, edit, delete tasks
- Assign tasks to projects
- Track task status (e.g., pending, in progress, completed)
- Automatically shows "Completed At" timestamp when status is set to `completed`

### 📁 Projects
- Create, view, update, delete projects
- Associate tasks with projects

### 👤 Authentication
- Register and login
- JWT-based authentication
- Persistent session with localStorage
